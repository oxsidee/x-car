# x-car — проводка Нивы 2131 в 3D

3D-схема проводки ВАЗ-21310 (Нива, 5 дверей), 2004 г., инжектор, ЭБУ Bosch MP7.0, аналоговая комбинация приборов. Каждый провод кликабельный: цвет, сечение, фишки и контакты, трасса, проверка, источники.

- `index.html` — интерфейс и 3D-сцена (three.js)
- `model.js` — модель кузова и шасси по чертежу 2131
- `data.js` — жгуты, провода, цвета, контакты ЭБУ и колодок щитка, источники

Приложение работает на порту **1865**.

## Запуск на сервере (Docker)

Нужны Docker и плагин Docker Compose. На Ubuntu/Debian их ставит официальный скрипт:

```bash
curl -fsSL https://get.docker.com | sh
```

Скачайте проект:

```bash
git clone https://github.com/oxsidee/x-car.git
```

Перейдите в папку проекта:

```bash
cd x-car
```

Соберите и запустите контейнер в фоне:

```bash
docker compose up -d --build
```

Откройте в браузере `http://<IP сервера>:1865`.

Если на сервере включён файрвол ufw, откройте порт:

```bash
sudo ufw allow 1865/tcp
```

Контейнер перезапускается сам после перезагрузки сервера (`restart: unless-stopped`).

### Обновление до новой версии

```bash
git pull && docker compose up -d --build
```

### Остановка

```bash
docker compose down
```

### Логи

```bash
docker compose logs -f
```

## Без Docker Compose

```bash
docker build -t x-car .
```

```bash
docker run -d --name x-car --restart unless-stopped -p 1865:1865 x-car
```

## Без Docker

Подойдёт любой статический веб-сервер, например:

```bash
python3 -m http.server 1865
```

Открывать через сервер, а не двойным кликом по файлу: модули браузер с `file://` не загрузит. В этом режиме three.js грузится с CDN, нужен интернет. В Docker-образе three.js лежит внутри, и 3D работает без интернета.

## Управление

- Мышь: левая кнопка — вращать, правая — сдвигать, колесо — зум, клик — описание провода.
- Сенсор: один палец — вращать, два пальца — зум и сдвиг, тап — описание, двойной тап — показать провод крупно (по пустому месту — сбросить вид), долгое нажатие — подсказка.
- «Скрыть меню» в шапке или клавиша H — остаётся только 3D-модель. Вернуть — кнопка «Показать меню» в углу или снова H.
