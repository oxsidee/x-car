# x-car — проводка Нивы 2131 в 3D

3D-схема проводки ВАЗ-21310 (Нива, 5 дверей), 2004 г., инжектор, ЭБУ Bosch MP7.0, аналоговая комбинация приборов. Каждый провод кликабельный: цвет, сечение, фишки и контакты, трасса, проверка, источники.

- `index.html` — интерфейс и 3D-сцена (three.js)
- `model.js` — модель кузова и шасси по чертежу 2131
- `data.js` — жгуты, провода, цвета, контакты ЭБУ и колодок щитка, источники
- `parts.js` — каталог запчастей по слоям (системам автомобиля) с местом на модели, описанием, проверкой и советами при замене

Приложение работает на порту **1865**.

## Подробная модель кузова

Если положить файл `models/niva.glb`, приложение покажет подробную модель вместо схематичной. Модель — эталон геометрии: её размеры не меняются, а провода, узлы, метки запчастей и агрегаты пересчитываются под неё по ориентирам, которые читаются из модели по именам деталей (колёса, бамперы, стёкла, пороги, фонари). Без файла работает схематичная модель.

С подробной моделью:

- провода и узлы вдавливаются внутрь её наружной поверхности и не вылезают за кузов;
- детали, которые в модели есть (колёса, диски, суппорты, пружины, рычаги, задняя балка, глушитель, бамперы, решётка, зеркала, брызговики, стёкла, ручки, дворники, сиденья, руль, панель приборов, капот, крылья, двери, крыша, боковины, дверь задка, фары, подфарники, повторители, фонари), выбираются и подсвечиваются прямо на модели, без схематичных меток; панели кузова нарезаются по стыкам дверей модели;
- схематичные агрегаты, которые дублируют модель, скрываются.

Модель — бесплатная [VAZ Lada Niva 4x4 2131 с 3dexport](https://3dexport.com/3d-model-vaz-lada-niva-4x4-2131-597162) под лицензией Royalty Free: её можно использовать в своём продукте, но нельзя распространять отдельным файлом. Поэтому в git она не хранится — скопируйте её на сервер отдельно:

```bash
scp models/niva.glb user@server:~/x-car/models/niva.glb
```

Docker Compose подключает папку `./models` в контейнер, пересборка не нужна — достаточно обновить страницу.

## Запуск на сервере (Docker)

Нужны Docker и плагин Docker Compose. На Ubuntu/Debian их ставит официальный скрипт:

```bash
curl -fsSL https://get.docker.com | sh
```

Скачайте проект:

```bash
git clone https://github.com/oxsidee/x-car.git
```

Перейдите в папку проекта:

```bash
cd x-car
```

Соберите и запустите контейнер в фоне:

```bash
docker compose up -d --build
```

Откройте в браузере `http://<IP сервера>:1865`.

Если на сервере включён файрвол ufw, откройте порт:

```bash
sudo ufw allow 1865/tcp
```

Контейнер перезапускается сам после перезагрузки сервера (`restart: unless-stopped`).

### Обновление до новой версии

```bash
git pull && docker compose up -d --build
```

### Остановка

```bash
docker compose down
```

### Логи

```bash
docker compose logs -f
```

## Без Docker Compose

```bash
docker build -t x-car .
```

```bash
docker run -d --name x-car --restart unless-stopped -p 1865:1865 x-car
```

## Без Docker

Подойдёт любой статический веб-сервер, например:

```bash
python3 -m http.server 1865
```

Открывать через сервер, а не двойным кликом по файлу: модули браузер с `file://` не загрузит. В этом режиме three.js грузится с CDN, нужен интернет. В Docker-образе three.js лежит внутри, и 3D работает без интернета.

## Управление

- Мышь: левая кнопка — вращать, правая — сдвигать, колесо — зум, клик — описание провода.
- Сенсор: один палец — вращать, два пальца — зум и сдвиг, тап — описание, двойной тап — показать провод крупно (по пустому месту — сбросить вид), долгое нажатие — подсказка.
- «Скрыть меню» в шапке или клавиша H — остаётся только 3D-модель. Вернуть — кнопка «Показать меню» в углу или снова H.
